## Verdict

FEASIBLE. Punchy AAA-style combat VFX are achievable with procedural assets only, pooled, budgeted and cheap. Do NOT build VFX on GPUParticles3D nodes: measured on Metal in 4.7.2 each active system costs about 33-36 us of frame time per frame, so 180 systems (60 effects x 3 layers) already exceed a 120 Hz frame (9.09 ms), 720 systems cost 28.6 ms and 2160 cost 76 ms. Recommended design: every short-lived effect is one instance in a MultiMesh ring buffer ("batch"), animated purely in shaders from a global clock `fx_time` (pause, game speed and fixed-step capture aware; never TIME). It needs no per-frame CPU work, uses 4 scene nodes and about 99 draw calls in the strategy benchmark, and costs 39-66 us of CPU per composite spawn, including all sub-layers. Lights (6 OmniLight3D) and scorch decals (48 Decal) are small node pools; long-lived sources (burning wreck, welding, beam impact, vehicle dust, contrail) are loop/stamper emitters that call the normal budgeted spawn(). Every spawn passes a per-class token bucket plus distance, projected-size and frustum culling, and every batch has a hard cap (its ring size). A prototype at prototypes/vfx implements 34 registered recipes (23 public effects, all requested effect families, plus 11 helper sub-effects and loop ticks), a pooled FxManager with a quality-preset switch, a camera-shake hook and cancelable superweapon warnings, a test arena, a 23-effect contact-sheet generator, a chaos-battle stress test, a first-spawn hitch test and a particle-strategy benchmark. Forward+ and Mobile render equivalently; Compatibility compiles everything but is visibly degraded (multi-quad cluster sprites render much smaller and dimmer, root cause not isolated). Limits of this spike: GPU timestamps do not work on Metal in 4.7.2 (viewport_get_measured_render_time_gpu returns 0.0) and the macOS window is display-paced at 120 Hz even with VSYNC_DISABLED, so cost is reported as CPU time, draw calls, primitives and load sweeps to the saturation knee, not GPU ms. Visual quality was iterated 4 times against real-renderer screenshots. It is strong for beams, rail, fireballs, sparks, missile and artillery trails, domes and orbital columns. It is modest for tiny impacts, wreck smoke contrast and heat shimmer (subtle in stills), and the terrain in the arena is flat.

## Key findings

1. FILES (prototypes/vfx, standalone project with its own .godot; tools/gd did not exist yet so the engine binary was used directly): src/fx_manager.gd (pools, clock, budgets, culling, emitters, lights, decals, quality, stats), fx_batch.gd (ring buffer), fx_recipes.gd (34 recipes), fx_assets.gd (noise atlas, HDR fire ramp, palette, scorch textures, meshes, materials), src/vfx_main.gd (arena + drivers), vfx_bench.gd; shaders/fx_sprites, fx_ribbon, fx_ring (blend_mix DISTORT variant injected via '#define DISTORT' after the shader_type line), fx_dome, fx_column, fx_shimmer, fx_common.gdshaderinc, fx_gpu_bench, arena_ground, arena_water. Typed GDScript, Fx* class names, liftable to game/src/view. Commit the generated .uid files.

2. RUN: G=tools/godot/Godot.app/Contents/MacOS/Godot; $G --headless --path prototypes/vfx --import; then $G --path prototypes/vfx [--rendering-method mobile|gl_compatibility] [--fixed-fps 60] [--resolution 1280x720] -- --mode=sheet --sheet=0..3 [--full=1 native frames] | --mode=chaos [--secs=15 --rate=5] | --mode=hitch [--prewarm=1] | --mode=bench [--counts=60,240,720 --warm --measure] | (no mode = interactive: click ground, keys 1-9,0, wheel zoom). Debug switches: --hide=<batch,...> drops layers to bisect artifacts, --noglow=1, --quality=low|medium|high|ultra, --tag=<suffix>.

3. API (all implemented in FxManager, a Node3D child of the view root at world origin, world-space metres, sim->view conversion x*3/1024): setup(camera, Quality); spawn(id: StringName, a: Vector3, b := Vector3.ZERO, scale := 1.0) -> int handle or -1 if culled/rate-limited/unknown (a = origin/muzzle, b = target for LINE effects, b.x = duration for sw_warning_marker); cancel(handle) for SUPER-class effects (launcher destroyed during warning); schedule(delay,id,a,b,s) (delayed sub-effects are re-culled when they fire); start_loop(id,a,b,scale,interval,duration); start_stamper(id,node,spacing,duration,scale) (stamps every N metres travelled, capped at 8 per frame); stop_emitter(h); prewarm() then clear_all() a few frames later; set_quality(LOW/MEDIUM/HIGH/ULTRA); paused / time_scale (bind to game speed); get_stats() / reset_stats(); signal camera_shake(amount, world_pos) with 140 m distance falloff; hidden_batches debug set.

4. TIERS: (A) FxBatch = MultiMesh ring buffer per look (33 batches, about 4.8k instance slots): fire, smoke, debris, rubble, sparks, dustring, dustcol, puff_dust/smoke/white, splash, flash, glow, gglow; ribbons tracer, trail, trail_dark, contrail, firetrail, beam, rail, arc, cone, shimmer; rings ring_add, ring_distort, ring_emp, marker, ripple, haze; dome, beacon, strike. INSTANCE_CUSTOM = (spawn_time, lifetime, palette index + random seed, param). Instance transform encodes geometry: sprite/cluster radius = uniform basis scale; ribbons use basis.x = parabolic arc offset, basis.y = B-A, basis.z = (tail length m, flight time s, linger s), origin = A, width in custom.w; rings use scale(R,1,R). Dead instances collapse to a degenerate vertex; a batch node sets visible=false when nothing is alive (constant draws = number of active kinds). Cluster meshes hold 9-20 pre-baked quads with per-vertex COLOR = 4 randoms and UV2.x = index/N for fx_lod thinning. (B) node pools: 6 shadowless OmniLight3D with quadratic energy decay, 48 Decal scorches (emission cools over 2 s, alpha fade over the last 4 s). (C) emitters for long-lived sources.

5. BUDGETS (FxManager consts): classes TINY/SMALL/MEDIUM/LARGE/BEAM/SUPER: max distance 70/110/200/350/200/inf m, min projected radius 2.5/4/6/8/3/0 px, token bucket refill 500/200/60/30/30/10 per s, burst 60/40/20/10/8/4; hard caps = ring sizes (puff_white 1024, puff_dust 768, tracer 512, puff_smoke 384, flash 256, cone 256, sparks 192, glow 192, fire/debris/smoke 128...). Culling is at spawn only (distance, projected radius via fov, frustum via unproject_position; LINE effects pass if either endpoint is visible). Quality presets: fx_lod 0.45/0.7/1/1 (thins cluster sprites through UV2.x), distance x0.6/0.8/1/1.4, lights 0/3/6/6, decals off/on/on/on, refraction off/off/on/on. LESSON: class distances must match the game's max zoom; TINY's 70 m silently culled contrail puffs at 105 m camera distance.

6. PROJECT SETTINGS the game needs: [shader_globals] fx_time and fx_lod (float) in project.godot (FxManager falls back to runtime add only if missing). Environment that made HDR VFX punch without smearing: ACES tonemap, glow ADDITIVE, intensity 0.8, hdr_threshold 3.0, hdr_scale 1.4, bloom 0, levels [0.6,1,1,0.8,0.5,0.25,0]; VFX use HDR 3-9 only for hot cores. Standard camera used: fov 38, pitch 52, yaw 20, 40-110 m distance.

7. LOOK RECIPES that worked: (1) premultiplied HDR ramp texture (256x1 RGBAH, rgb = glow+smoke premultiplied, a = coverage) indexed by 'heat' renders fire that cools to sooty smoke in ONE blend pass; (2) one 256^2 RGBA8 noise atlas (R fbm, G inverted cellular, B smooth, A grit; 0.35 MB with mips) gives erosion, billow, fake lighting (second fetch offset toward the light) and beam flicker; (3) analytic ballistic motion for debris (lands and rests; 'rubble' variant persists 30 s), sparks (velocity-aligned streaks with gravity), splash droplets; (4) ribbon shader per-point aging gives smoke trails that linger and widen with zero CPU; (5) hex-grid energy dome with rim fresnel and a rising wave; (6) descending kinetic column that lands into a lingering pillar; (7) marker ring with dashes, counter-rotating spokes, clock-sweep fill and pulse rate rising with time; (8) screen-texture refraction for shockwave, EMP and heat haze; (9) screen-space minimum width (2.6 px) for thin streaks.

8. EFFECT CATALOGUE (id: class, scale meaning): rifle_shot, mg_burst (SMALL, size x); cannon_shot, cannon_impact, explosion_small/medium/large (MEDIUM/LARGE, radius 1.8/3.6/8 m x scale; composition scales with radius: glow, star flash, ground glow, fire, smoke, sparks, debris, refraction + additive ring, dust ring, dust column, light, scorch, shake); missile_launch (backblast, lingering smoke ribbon, exhaust tracer, medium blast); artillery_shell (parabolic ribbon + large blast); beam_thermal (beam + shimmer ribbon + hot impact loop + scorch); beam_rail (helix streak + blue impact); emp_pulse (AREA, scale = radius m; rings, 14 crackling arcs, refraction); vehicle_destroy (+14 s wreck fire/smoke loop); building_collapse (footprint x 7 m; debris, persistent rubble, staggered dust bursts, shake); infantry_hit, impact_ground, impact_water (splash + ripple), vehicle_dust and aircraft_contrail (stampers), aircraft_crash (dark smoke + fire ribbons -> large blast -> wreck loop), construction_sparks (loop); SUPER class: sw_warning_marker (scale = radius m, cancelable), sw_orbital_strike (3 penetrators 9 m apart, 6 m radius), sw_shockwave (9 m core + 21 m ring + white-out), sw_microwave_dome (24 m hex dome + haze + arcs). Geometry follows the bible (1 cell = 3 m): Atlas 3x2-cell, Aurora 8-cell, Perun 3+7-cell.

9. RENDERERS (chaos sheet 1 on each): all 8 shaders compile with 0 errors on Forward+, Mobile and Compatibility (MultiMesh custom data, global uniforms, #include, #define variants, hint_screen_texture, hint_depth_texture, Decal, glow all work). Mobile: visually equivalent, bloom halo around beams weaker (bump glow for that preset), chaos p50 +2.3 ms vs baseline on this GPU. Compatibility: ribbons, rings, refraction, dome, columns and single-quad glows work (refraction ring looks thicker/glassier); depth-texture soft fade needed NDC z = d*2-1 there (now a `depth_ndc` uniform set from RenderingServer.get_current_rendering_method(), and soft depth is disabled on Compat); BUT multi-quad cluster sprites (fire, smoke, dust, debris) still render visibly smaller and dimmer than Forward+ even after that (root cause not isolated; suspects: LDR buffer clamping of HDR values, instance-transform handling under skip_vertex_transform in the GLES3 backend). Compat needs a dedicated pass before it counts as playable-with-downgrades. Sheets 0, 2, 3 were not captured on Mobile/Compat.

10. PITFALL: `return` inside a shader vertex() is a compile error in 4.7.2 ('Using return in the vertex processor function is incorrect'); compute a `dead` flag and collapse VERTEX at the end.

11. PITFALL: RenderingServer.global_shader_parameter_get_list() logs an error outside the editor; declare globals in project.godot [shader_globals] and only add at runtime if ProjectSettings lacks them.

12. PITFALL: instance uniforms on nodes hit 'Too many instances using shader instance variables. Increase buffer size in Project Settings' between 2.4k (ok) and 9.6k nodes; do not use per-node instance uniforms for VFX. MultiMesh custom data has no such cap.

13. PITFALL: additive billboards are clipped flat by the terrain (hard horizontal cut on glow discs); in the vertex shader pull them 0.6*size toward the camera in view space.

14. PITFALL: a bloom threshold below lit-terrain brightness (2.2) plus a fixed-width additive shock ring produced a milky cream 'plate' with a crisp rim over every big explosion. Bisected with --hide (ring_add was the layer; col=0 removed it; glow off shrank it). Fixed with a dim, radius-relative exponential ring profile and hdr_threshold 3.0. Lesson: judge VFX with the final glow/tonemap on, and keep a layer-hiding debug switch.

15. PITFALL: hint_screen_texture (refraction) only contains what was drawn before the transparent pass; give it render_priority -9/-10 or it overwrites smoke. The full-screen copy only happens while a distortion batch is visible.

16. PITFALL: dust and smoke tints must contrast the terrain palette (the first version was invisible on beige ground); sprites need a lit floor in the fake-lighting term.

17. PITFALL: FastNoiseLite.get_seamless_image returns L8; pack 4 layers into RGBA8 (one fetch = 4 noise layers). Image.create is deprecated, use create_empty. Sprite quads with soft depth need `varying` view-space z, not the mesh VERTEX, when skip_vertex_transform is used.

18. PITFALL: GPU timing is unavailable on Metal (0.0) and windowed macOS is display-paced (p50 = 8.333 ms quantum) even with VSYNC_DISABLED, so any frame below 8.33 ms is unresolved and only overruns are real; use render-thread CPU, draw calls, primitives and load sweeps.

19. OPEN ITEM: heat shimmer is subtle in stills (ribbon refraction strength 2.2 is barely visible at 40 m zoom); wreck smoke is low-contrast on dark hulls; impact_ground and infantry_hit are small at 60 m+ zoom (scale with camera distance); rings/decals/glow are flat (arena has no height); premultiplied layers are unsorted inside a batch (minor artifacts between fire and smoke).

20. WITH MORE TIME: fix Compat cluster sprites; terrain-height-aware rings/decals (height sampler or terrain splat map); authored flipbook smoke with directional lighting; faction tint via palette index; camera-distance-scaled small effects; GPU debris landing on terrain height; audio/shake sync; automatic quality scaling from measured frame time; real GPU timing via Instruments/RenderDoc on non-Metal hardware; second refraction layer for stronger heat haze; fixed sort order for premultiplied layers.

21. CROSS_MODULE_REQUESTS: (1) game/project.godot: add [shader_globals] fx_time, fx_lod (float). (2) view/: own an FxManager child at world origin, call setup(camera, quality) and prewarm() behind the loading screen (34 recipes, 8 frames), bind time_scale/paused to game speed/pause, connect camera_shake to the RTS camera rig, add an FxEventRouter mapping SimEvents to spawn(). (3) sim events needed (output-only): WEAPON_FIRED(weapon, from, to), IMPACT(pos, surface ground|water|structure), ENTITY_DIED(size class), STRUCTURE_DESTROYED, SW_WARNING_START/CANCEL/FIRE(id, pos, radius, seconds), EMP_APPLIED. (4) balance layer: per-weapon fx block {muzzle, tracer, impact, scale, tracer_speed}. (5) tools/gd: does not exist yet; this prototype used the engine binary directly (own .godot, no lock conflict).
